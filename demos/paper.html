Experience, Projects, and Bounds

Alina Du

Columbia University, Department of Computer Science

resume.pdfgithublinkedinemail

Abstract

We present a Computer Science student at Columbia University, minoring in Financial Engineering and Mathematics. The work spans ML research, data engineering and software engineering, including LLM verification under a fixed budget, prediction on tokamak shot data, and an AI course planner used by over 1,000 students. We describe six positions (§1), five projects (§2) and several results in competition mathematics (§3).

2Projects

2.1  Lionplan.ai [1]

An AI course planner used by 1,000+ students, with a 4-year planner, conflict detection, and an agent that adds, drops and swaps courses against prereq rules. Built on 30K+ parsed reviews and 4.6K+ courses. Next.js · TypeScript · Python · Postgres · Claude API

2.2  Pac-Manhattan [2]

Pac-Man on a 3D model of NYC where you play the ghost. 171K buildings in Three.js and A* pathfinding over the real street graph. JavaScript · Three.js · Python · Gemini API · ElevenLabs

2.3  Home Again [3]

A game that brings families together around a loved one living with dementia. Photos, voice messages and songs become a gentle walk through their own life story, in a three.js dollhouse. JavaScript · Node.js · Three.js · Gemini API · Postgres · Snowflake

2.4  Hack the Heart [4]

Two AI agents learn how two people text, then go on a simulated date to guess whether the real people would get along. Python · FastAPI · Next.js · MongoDB

2.5  Think Before You Trust [5]

Research code for choosing which steps of an LLM's reasoning to verify under a fixed budget. Python · PyTorch · LLM evaluation
